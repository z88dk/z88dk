?? Graphics features absent on the ZX81
The ZX81 has only a 64x48 pseudo-graphics grid via PRINT characters. The Spectrum adds a full pixel graphics subsystem:

PLOT x,y - plots a pixel on a 256x176 grid (ZX81 has only character graphics) 

DRAW dx,dy - line drawing

CIRCLE x,y,r - circle drawing

INK, PAPER, BRIGHT, FLASH, OVER, INVERSE - color and attribute control

SCREEN$ - access to screen memory

User-Defined Graphics (UDG) - redefinable 8x8 characters (ZX81 only has fixed character set) 

The ZX81 has no pixel graphics, no color, no UDG, and no attribute control.

?? Sound features absent on the ZX81
The ZX81 has no sound hardware and no sound commands.

Spectrum adds:

BEEP duration,pitch - built-in sound generation 

?? Mathematical functions absent on the ZX81
ZX81 BASIC has floating point and basic trig/log functions, but the Spectrum expands the math library:

PI constant (ZX81 lacks PI) 

Additional floating-point routines in ROM (more complete and faster)

More robust numeric expression handling

?? Data & variable features absent on the ZX81
ZX81 variables are extremely limited (single-letter + optional digit). Spectrum adds:

Full string slicing: A$(3 TO 5)

VAL, STR$, CHR$, CODE - richer string/numeric conversion

BIN, INKEY$, PEEK, POKE - ZX81 has PEEK/POKE, but Spectrum extends memory access and keyboard handling

ATTR, POINT, SCREEN$ - screen inspection functions

?? System & environment features absent on the ZX81
Spectrum BASIC integrates many OS-level features not present on the ZX81:

LOAD, SAVE, VERIFY with tape headers and auto-start

MERGE - merge BASIC programs

RANDOMIZE - seed RNG

CLEAR - memory management

CLS - clear screen (ZX81 uses PRINT statements to clear)

CONT - continue after break

LIST, EDIT, COPY, MOVE - advanced editor functions (ZX81 editor is extremely primitive)

ERROR messages with full text (ZX81 uses numeric codes)

?? Control-flow and structural features absent on the ZX81
ZX81 BASIC is minimal. Spectrum adds:

ON x GOTO/GOSUB - computed jumps

REPEAT / UNTIL (in later Spectrum variants)

PAUSE - timed delay

STOP - explicit program stop (ZX81 uses END only)

?? Input/output features absent on the ZX81
INKEY$ - non-blocking key read

KEYWORDS via single-key entry (ZX81 has this too, but Spectrum expands the keyword set)

LPRINT, LLIST - printer output

FORMAT (later models)

?? Character set differences
ZX81 uses a custom, non-ASCII character set with block graphics.

Spectrum uses a near-ASCII set with no ZX81 half-tone graphics.

?? Display-mode differences
ZX81 has FAST and SLOW modes (CPU vs video timing).

Spectrum does not have FAST/SLOW - screen is generated by hardware.
