## Address proof

The baseline plain prologue used `ld hl,-10; add hl,sp; ld sp,hl`. The new prologue uses `lea hl,ix-10; ld sp,hl`. A 128-byte frame uses `lea hl,ix-128`. A 129-byte frame keeps the SP form.

The long fastcall case pushes DE and HL after setting IX. Its remaining allocation is 16 bytes, and its full frame is 20 bytes. The old sequence used `ld hl,-16; add hl,sp`. The new sequence uses `lea hl,ix-20`. Both set SP to the same address.
